# Songdial

> Tune into the right music.

Songdial is a discovery-first terminal music application. It brings moods,
radio stations, personal playlists, and search into one coherent interface,
independent of where the music comes from.

Songdial is currently in product-definition stage. The first milestone is an
interactive TUI backed by realistic demo content so its navigation and
discovery experience can be validated before real playback integrations are
introduced.
